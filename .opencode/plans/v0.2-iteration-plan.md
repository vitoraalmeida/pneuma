# Plano v0.2 — Git-aware OCI Delivery

**Status:** Planejamento concluído, pronto para implementação

## Visão geral

Objetivo: tornar o Pneuma um sistema de **discovery e deployment** de artifacts OCI produzidos pelo CI. Pneuma deixa de construir aplicações; o fluxo passa a ser `Git branch → commit → OCI digest → Release → deployment`.

| **4** | E+F+G | Deploy por branch (`--branch staging`) | Pendente |
| **5** | H | Migrar website para o novo fluxo | Pendente |
