# v0.1 and v0.2 Delivery Detail

**Status:** historical record.

This preserves the detailed delivery-oriented view that previously occupied the
main roadmap. It records planning language and superseded models; current
architecture is documented in [`../architecture/architecture.md`](../architecture/architecture.md)
and [`../architecture/data-model.md`](../architecture/data-model.md).

## v0.1 - OCI Foundation

v0.1 established Application registration, immutable OCI deployment, runtime
health verification, Caddy exposure, deployment history, rollback, and host
operation.

### Delivered Capabilities

- Application catalog, System grouping, SQLite migrations, Deployment state
  machine, RuntimeInstance persistence, start/stop/status, and Deployment
  history.
- Rootless Podman runtime, internal and external health checks, safe traffic
  switch, Caddy exposure, visibility changes, rollback, `doctor`, and
  backup/restore.
- Release and DeployRelease refactoring, including rollback as a new Deployment.
- OCI pull/inspect validation, digest-only deploy input, repository enforcement,
  and manifest delivery configuration.

### Superseded v0.1 Delivery Paths

- `app deploy-source` and `deployment_deploy_source.rs`.
- Local image builds and the `local_build` module.
- `[source]` and `[build]` manifest sections.
- Local-path import.

The planning model initially associated source revision with Release. That was
superseded in v0.3: Release is artifact-only and source provenance belongs to
Deployment.

## v0.2 - Git-Aware OCI Delivery

v0.2 changed Pneuma from operating an OCI image supplied by an operator to
resolving and deploying the artifact for a Git revision. CI produced the image;
Pneuma discovered and activated its digest.

| Phase | Historical delivery result |
|---|---|
| A | Removed local builds, permanent build checkouts, `deploy-source`, and build manifest configuration. |
| B | Introduced capability-oriented SQLite stores for application, Deployment, RuntimeInstance, and Release persistence. |
| C | Introduced manifest schema v3 and forward-only migrations. |
| D | Added remote-Git import with temporary checkout and persisted repository/manifest metadata. |
| E | Added Git branch/tag resolution to an immutable full commit SHA. |
| F | Added OCI tag discovery followed by digest resolution; current behavior uses `repository:<commit-sha>`. |
| G | Added branch deployment and persisted source revision on Deployment. |
| H | Validated the Git-to-OCI deployment flow for the pilot application. |

Earlier documents called the lookup an ``image:<commit>`` convention and placed
source correlation on Release. The implemented code resolves
`repository:<commit-sha>` to a digest, and current architecture stores source
revision on Deployment. This record preserves the evolution rather than treating
the earlier formulation as current truth.
